# DESIGN_SYSTEM.md

# Design Philosophy

The website should feel:

- Premium
- Minimal
- Elegant
- Modern
- Trustworthy

The design should NOT feel:

- Cheap
- Colorful
- Busy
- Cartoonish
- Template-like

Imagine a mix between:

- Apple
- Muji
- Uniqlo
- Aarong

The goal is to let the products stand out.

---

# Target Audience

People from Bangladesh buying traditional clothing.

Age:

18-60

Many users will use Android phones.

Prioritize mobile experience.

---

# Overall Feeling

The UI should feel calm.

Use lots of whitespace.

Avoid unnecessary decorations.

Typography should be clean.

The product photography should be the focus.

---

---

# Typography

Use modern fonts. For Bangla text use Hind Siliguri. For English text use Inter.

Headings:

Bold

Body:

Regular

Keep line height generous.

Avoid tiny fonts.

---

# Border Radius

Buttons

Medium rounded

Cards

Large rounded

Inputs

Medium rounded

---

# Shadows

Use soft shadows.

Never use heavy shadows.

---

# Buttons

Primary:

Filled

Secondary:

Outlined

Danger:

Red

Ghost:

Transparent

Buttons should always have:

- hover state
- loading state
- disabled state

---

# Cards

Product cards should include:

Product Image

Product Name

Price

Discount

Wishlist Icon

Quick Add To Cart

Hover Effect

---

# Images

Large.

High quality.

Consistent aspect ratio.

Never stretch images.

---

# Animations

Very subtle.

Hover elevation.

Fade in.

No bouncing.

No spinning.

No flashy effects.

---

# Spacing

Use generous spacing.

Avoid crowded layouts.

# Design Rules

Always:

- Keep layouts simple.
- Prioritize readability.
- Use whitespace generously.
- Focus on product imagery.
- Follow consistent spacing.
- Maintain consistent colors.

Never:

- Add unnecessary gradients.
- Use random colors.
- Overuse animations.
- Create cluttered layouts.
